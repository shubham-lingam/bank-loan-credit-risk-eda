# 📂 Dataset

The dataset used in this project is the **Bank Loan Data** dataset available on Kaggle.

The raw dataset is not included in this repository.

### Dataset Source

Kaggle — Bank Loan Data

The dataset contains **45,000 loan applications and 14 original variables** covering borrower characteristics, loan information, credit profiles, previous defaults, and loan status.

Please download the dataset from the original Kaggle source and place the required CSV file in this folder if you want to reproduce the analysis locally.

### Dataset Link

https://www.kaggle.com/datasets/udaymalviya/bank-loan-data
